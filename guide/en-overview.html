Modular Housing for the U.S. (California) Market — Framework & Operating Manual ​

Executive Summary（交付包总览 · English Overview） ​

Prepared by: Modular-Agent（modular housing knowledge specialist） Scope: Complete technical + compliance framework and operating manual for Chinese Modular Housing suppliers entering the California market, benchmarked to U.S. (ASTM/AISC/NDS/ACI/NFPA/UL) and Federal (HUD/FHA/ADA/OSHA) standards, with US↔China standard correspondence for domestic factory alignment.

1. What This Package Is ​

A 7-part deliverable set that functions as both a global operating manual and per-structural-type spec templates. It answers: what technical/process requirements apply globally, which sections are shared vs. type-specific, and how to write each SECTION to US spec with CN correspondence.

2. Global Compliance Pathway (All Types) ​

California FBH path (primary): Product type → DAA delegated design approval (CA licensed SE) → QAA/HCD factory inspection (Title 25 §3032: 100%→first 10 units→25%) → HCD insignia (HSC §19980) → local AHJ permit/install/CO → delivery (SB 800 warranty). Dual-track: HCD governs factory product+quality; local AHJ governs site install+occupancy.

Six Gates (G1-6): Compliance path lock → design freeze (DAA) → production start (FQP) → module ex-factory release (FAT/insignia/triple-release) → site structural closeout → occupancy/CO.

Federal layer (overlay, not replacement): HUD 24 CFR 3280 (optional, default excluded), FHA/HUD MPS, ADA 2010 + CA Ch.11B, Fair Housing, Lead 40 CFR 745, OSHA 29 CFR 1910/1926, import compliance (ISPM-15 timber, steel tariffs).

3. Shared vs. Type-Specific Chapters ​

Shared (in 01 + 06): Div 00 procurement / 01 general(submittals-QA-QC-rigging-execution-closeout) / 07 envelope / 13 generic module core / 14 vertical transport / 21-28 MEP interface language / 31-33 site / 48 PV + materials list(CN↔US).

Type-specific (each template only):

  • Steel (02): Div 05 12/31/50 + steel module FAT/SAT
  • Concrete/UHPC (03): Div 03 10/33 + 13 34 23 (ESR-5874)
  • Wood (04): Div 06 05/10/13/16/17/20 + Div 09 fire separation

4. US↔China Standard Correspondence（Key Differentiator for Chinese Suppliers） ​

Each material carries a US baseline (enforceable) + CN equivalent (for factory alignment). Examples: Q355→A992, Q235→A36, GB 50017↔AISC 360+GB 50011↔AISC 341, GB/T 13912↔ASTM A123/A153 galvanizing, GB 8624-2008↔ASTM E84 fire class, GB/T 6952↔ASME A112.19/WaterSense fixtures, GB/T 26899↔PRG-320 CLT, ESR-5874↔T/CECS UHPC. Principle: US standard = sole acceptance baseline; CN standard = production/cost alignment only; differences (impact toughness, coating thickness, fire class, water efficiency) documented item-by-item.

5. Ready-to-Use Deliverables for the Supply Chain ​

  • 06 materials/equipment list → write each "Products/Materials" subsection with US performance + CN correspondence.
  • 07 full SECTION 05 12 00 → production-ready MasterFormat 3-part spec with material substitution table (CN↔US), measurable acceptance criteria, and 3 hold points (HP-1 ex-factory/FAT, HP-2 pre-connection, HP-3 post-connection before conceal) mapped to Gates 4/5.
  • Same 3-part template applies to every SECTION across all three structural types.

6. Platform & Live Radar (Forward Direction) ​

This framework is the seed content for an open platform serving Chinese modular integrators and trade suppliers entering the U.S. market. Platform layers:

  • L1 Knowledge Base: integrates the master spec-agent library (Modular Housing = a specialized view of it) + these deliverables.
  • L2 Live Radar: per-category competitor benchmarking (each category's most advanced benchmark, dynamically refreshed) + standard/code change tracking (IBC/CBC/ASCE 7/AISC/NDS/ACI/ASTM/ICC-ES ESR, HCD Title 25, tariffs); tracking-list released, cron auto-reporting next.
  • L3 Advisory/Tech-justification services: product US-standard review, spec deepening, approval-process pathways, and lifecycle stakeholder roles/responsibilities/obligations.
  • L4 Ops hub: distills accumulated knowledge; selectively publishes items tagged Modular House from the knowledge-channel building graph.

Build approach: static site first, Chinese-primary with i18n English toggle reserved; public (no membership); tracking-list-first → then cron automation.
