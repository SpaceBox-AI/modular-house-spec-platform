完整版 MasterFormat SPEC 框架 ​

本站主目录导航骨架 = 一套由 12 份引导文件推导出的完整版美标 MasterFormat SPEC 框架（Division 00-48）。 Modular House 是 spec-agent 大库（MasterFormat 母本）的特例视图：此处呈现其在模块化装配式语境下的完整章节树。

导航方式 ​

有两种浏览方式（同一套内容，两种挂载）：

  • 按 Division（跨类型通用章节）：见左侧 spec/divisions/*——每个 Division 一页，含该分部下可投用的 SECTION 编号 + 各结构类型是否适用。
  • 按结构类型（Section 的各类型展开）：见 spec/types/*——钢 / 混凝土UHPC / 木，三项视图把同一套 Framework 按类型切分。
