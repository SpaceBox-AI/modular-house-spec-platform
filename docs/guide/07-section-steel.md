## PART 1 — GENERAL（一般要求）

### 1.1 章节范围（Section Includes / 章节包括）

- 钢结构模块之**结构钢框架与底盘**：主梁/柱（W 型钢）、角钢/钢板次构件、剪力连接栓钉、模块间结构连接节点（螺栓/焊接/连接板）之**委派设计、加工、安装、检测与防腐**。
- 现场拼接节点、吊装临时锚固件、模块与基础之锚栓/连接界面。
- 横向关联：Division 01 33（提交）/01 43（QA）/01 66（吊装）、03 30（锚栓基础）、05 31（钢质楼板）、05 50（金属制品/吊点保护）、13 42（模块本体）、13 48（抗震连接）。

### 1.2 引用文件（纳入合同与规范）

- **AISC 360**（结构钢建筑规范）+ AISC *Design, Fabrication and Erection*（加工安装执行基准）`[spec-agent 05]`
- **AISC S348 / RCSC**（用 ASTM A325/A490 螺栓之结构连接）`[spec-agent 05]`
- **AWS D1.1/D1.1M** 钢结构焊接规范；**AWS D1.8/D1.8M** 抗震补编（加州 D/E 级结构适用）
- **ASTM A992/A992M**、**ASTM A36/A36M**、**ASTM A325/A490**、**ASTM A307 Gr.A + A153/A153M**（镀锌）
- **AISI S100 / S240**（如需冷弯承重墙柱 CFS）
- 加州/联邦：**CBC（Title 24 Part 2，基于 IBC）+ ASCE 7**（抗震）、**AISC 341**（抗震设计）、**HCD 25 §3032**（检验频率）、**HSC §19980**（insignia）、**CFC（Part 9）** 防火、**CEC（Part 6）** 节能。
- 中美对应：**GB/T 1591（Q355→A992）、GB/T 700（Q235→A36）、GB 50017（钢构）、GB 50011（抗震）、GB/T 13912（镀锌）** ——详见下方 2.1「材料替换换算表」。

### 1.3 提交要求（Submittals）

- 委派设计计算书 + **加州执照结构工程师（SE）复核签字**图纸副本（DAA 版=现场版）。
- 材料证书（mill certificate）——涵盖 ASTM 力学性能 + GB 成分对照。
- 焊接程序评定报告（PQR）+ 焊工资质（AWS/CWB）；扭矩标定记录；NDT 报告（UT/MT）。
- **FAT 清单**（出厂前）、**ITP/检验试验计划**。
- 防腐涂层/镀锌体系数据表。

### 1.4 质量保证（QA）

- 制造厂须具 **AISC-certified（Qc/Qa）** 或等效出海焊接质量体系；具备**加州赴厂检验接待能力**（对标 CIMC-MBS 先例）。
- 第三方 QAA 持证检验；检率依 **Title 25 §3032**：新型号 100%→首10台全检→可降频至 25%。

### 1.5 交货与存储（Delivery/Storage）

- 运输按 Division 01 66 + Caltrans 限重限高；构件加固防变形；到货损伤如实记录并 NCR 关闭后方可安装。

## PART 2 — PRODUCTS（产品/材料）

### 2.1 材料替换换算表（中美对应，写入采购）★

> 美标=验收基准；中标为国内对标/采购选用。选材时逐项核对力学与工艺差异。

| 部位 | 美国标准（验收基准） | 中国对应规范 | 差异处理 |
|---|---|---|---|
| 主框架 W 型钢 | **ASTM A992**（≥50ksi/345MPa） | **GB/T 1591 Q355** | 屈服/抗拉/冲击/焊性逐项对标，取等效；现场以美标 mill certificate 为准 |
| 角钢/钢板/次构件 | **ASTM A36**（≥36ksi/250MPa） | **GB/T 700 Q235** | 同上 |
| 连接板材/节点板 | A572 Gr.50 或 A992 | GB/T 1591 Q355 | 节点受力按 AISC 360 验算 |
| 高强度螺栓 | **A325/A490**（摩擦型）+ **AISC S348/RCSC** | GB/T 1228（10.9S）+ GB/T 1231 | 扭矩系数/预拉力按美标标定 |
| 普通镀锌螺栓/螺母 | **A307 Gr.A + A153/A153M Class C** | GB/T 5782 + **GB/T 13912 镀锌** | 镀层厚度按 A153 验收 |
| 剪力连接栓钉 | 锻钢有头，**AWS D1.1 Type B** | GB/T 10433（栓钉）| 力学等级/焊接工艺对标 |
| 结构设计/抗震 | AISC 360 + AISC 341 + ASCE 7 + CBC | **GB 50017 / GB 50011** | 加州以 AISC/CBC 为验收；中标内部设计参考 |
| 热浸镀锌 | ASTM A123/A153 | **GB/T 13912-2002 / GB/T 5267.3** `[spec-agent原文]` | 镀层等级双向核对 |

### 2.2 材料构件

- **主结构**：ASTM A992（W 型）主梁柱/角柱/底盘；ASTM A36 次构件与节点板；全部附材料证书。
- **连接受力件**：A325/A490 摩擦型高强螺栓；A307 Gr.A 镀锌普通螺栓/螺母；锻钢有头剪力连接栓钉（AWS D1.1 Type B）`[spec-agent 05]`。
- 冷弯承重墙柱（CFS，如需）：热浸镀锌冷弯钢，依 **AISI S100/S240** + 美国 **ASTM A1003 A 级**；对标中国 GB/T 6723 / JG/T 182。

### 2.3 焊材与工艺

- 焊材依 **AWS D1.1**（承重）/ **AWS D1.8**（抗震）规定；PQR/WPS 先行评定；焊工 AWS/CWB 持证。
- 剪力连接栓钉焊接同 AWS D1.1 Type B。

### 2.4 防腐

- 室外/接触土壤与运输暴露构件按环境类别做涂层或热浸镀锌（ASTM A123/A153）；模块间拼接处现场补涂。
- 对标：中国 GB/T 13912 热浸镀锌、GB/T 27806 环氧沥青涂料（内部对标）。

## PART 3 — EXECUTION（安装与执行）

### 3.1 工厂加工与出厂（FC 段）

- 框架拼焊→焊检（VT 100% + 关键缝 UT/MT）→底盘校准→栓接扭矩逐栓记录→防腐→**FAT**→加固出厂。
- 出厂停点：材料证书齐、焊接/扭矩记录齐、FAT 通过。

### 3.2 现场架设（现场段）

- 依批准的架设顺序（*Sequence of erection by professional steel structure company*）`[spec-agent 05]`；**专业结构队伍 + 有经验起重/stager** `[spec-agent 05]`。
- 使用移动式起重机、钢制吊索与合适吊装硬件 `[源文档 05 50]`；吊点经 SE 复核。
- **连接前**：校准垂直度/对齐后再螺栓或焊接固定 `[源文档 05 50]`。

### 3.3 模块间连接执行

- 就位→临时支撑→最终连接（栓/焊）→扭矩/焊缝检验→隐蔽前验收。
- 摩擦型高强螺栓按 **AISC S348/RCSC** 安装，终拧扭矩成组取样 + 标定留存；扭矩值=工程师设计规定值 `[源文档 05 50]`。
- 现场拼接节点由委派设计出图（连接板/销轴/角柱锁紧），依图执行并**纳入第三方检测**。

### 3.4 检验与停点（Hold Points）★★★★

| 停点 | 时机 | 验收项 | 放行 |
|---|---|---|---|
| **HP-1** | 出厂前 | 材料证书+焊接记录+扭矩抽查+FAT | 工厂 QAA 签 + insignia |
| **HP-2** | 现场拼接前 | 基础/承面交接、锚栓复核（±2mm）、吊装安全交底 | 现场验收单 |
| **HP-3** | 连接后/隐蔽前 | 扭矩记录齐、NDT 通过、第三方结构检验 | NCR 关闭 + 三重放行 |

- 抗震焊缝按 **AWS D1.8**；关键全熔透焊缝按图纸 UT/MT。
- 检验嵌入 **Gate 1-6**（见 `00_操作手册总纲` A.2）：HP-1↔Gate 4，HP-2/3↔Gate 5。

### 3.5 现场清理与保护

- 清除焊渣/临时固定件；补涂螺栓界面与防腐；接口面清洁后可隐蔽。
