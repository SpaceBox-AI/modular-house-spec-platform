## 2. Global Compliance Pathway (All Types)

**California FBH path (primary):**
Product type → **DAA** delegated design approval (CA licensed SE) → **QAA/HCD** factory inspection (Title 25 §3032: 100%→first 10 units→25%) → **HCD insignia** (HSC §19980) → local AHJ permit/install/CO → delivery (SB 800 warranty). Dual-track: HCD governs factory product+quality; local AHJ governs site install+occupancy.

**Six Gates (G1-6):** Compliance path lock → design freeze (DAA) → production start (FQP) → module ex-factory release (FAT/insignia/triple-release) → site structural closeout → occupancy/CO.

**Federal layer (overlay, not replacement):** HUD 24 CFR 3280 (optional, default excluded), FHA/HUD MPS, ADA 2010 + CA Ch.11B, Fair Housing, Lead 40 CFR 745, OSHA 29 CFR 1910/1926, import compliance (ISPM-15 timber, steel tariffs).

## 4. US↔China Standard Correspondence（Key Differentiator for Chinese Suppliers）

Each material carries a **US baseline (enforceable) + CN equivalent (for factory alignment)**. Examples: Q355→A992, Q235→A36, GB 50017↔AISC 360+GB 50011↔AISC 341, GB/T 13912↔ASTM A123/A153 galvanizing, GB 8624-2008↔ASTM E84 fire class, GB/T 6952↔ASME A112.19/WaterSense fixtures, GB/T 26899↔PRG-320 CLT, ESR-5874↔T/CECS UHPC. **Principle:** US standard = sole acceptance baseline; CN standard = production/cost alignment only; differences (impact toughness, coating thickness, fire class, water efficiency) documented item-by-item.
