# 05 材料与设备清单 → 章节分布 → 美标性能要求（全类型共用 + 结构类型差异）

> 📌 **本文件是「材料设备清单 → 章节分布 → 按美国规范做性能描述」的贯串索引**。
> - 依据：已解析资料（`模块化建筑章节映射表` 8 工作表、ADU 钢构方案、汉尔姆 MEP、盈创 3D 打印混凝土、意大利钢构手册、sekisui/TOTO 卫浴、washroom、加州供应商研究报告）+ spec-agent 美标模板 + `01_共享框架合规底座` §0.4 规范分布矩阵。（入口总纲：`00_操作手册总纲`）
> - 用法：**采购/深化阶段**据此把每项材料设备写成 SECTION 的「产品/材料/供应商」子节，性能要求句挂对应美标。

## 0.0 中美标准对应总表（GB ↔ US，供中国供应商对标）★本文件亮点★

## 七、把清单落成 SECTION 的写法（示例：保温 07 21 00）

> 每项材料描述采用 spec-agent 三段式「产品/性能/装配」子节，性能句挂在美标上；流程句挂在加州/联邦锚点上。

```
### 07 21 00 保温（产品子节）
- 保温材料：闭孔聚苯乙烯（EPS, ASTM C578 Class I）、矿棉板（ASTM C591）或 XPS（ASTM C578）；
  以工程部位热工设计要求选择R值，整模块外保温连续、现场接缝补环保温（对齐 0.4 加州CBC节能）。
- 性能：整装配消防热桥控制，R/U 值满足 Title 24 Part 6 装配表；材料火焰蔓延等 CABO/UL 723（ASTM E84）≤25；
  在装配体隔层/结构与围护间保持气密连续性（07 27）。
- 装配/检验：工厂段出厂验收（FAT）、现场接缝部位补环保温、隐蔽前 hold point（01 33/01 45）。
```
