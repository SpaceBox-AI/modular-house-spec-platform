## A. 全局市场准入技术与流程总览（所有结构类型一致）

### A.1 加州法规主路径（FBH Factory-Built Housing）

```
产品定型
  │ 锁定 FBH 路径（HSC §19980 / Title 25 Ch.3 Subch.1）
  │ 结构类型选择（钢 / 混凝土UHPC / 木）→ 见对应类型模版
  ↓
DAA 设计批准（第三方审图，加州执业 SE 复核）
  │ 委派设计（结构/底盘/吊装/MEP集成）→ DAA 批准图纸 = 现场许可版本
  ↓
QAA / HCD 工厂质量检验
  │ Title 25 §3032：新型号100% → 首10台全检 → 可降频至25%
  ↓
HCD insignia 出厂贴附（HSC §19980）
  │ 三重放行门槛：①DAA版图纸=现场版 ②QAA+insignia ③NCR关闭
  ↓
地方 AHJ 现场许可 / 安装 / 基础 / 接口 / CO
  │ 双轨并行：HCD 管工厂产品+质量；地方 AHJ 管现场安装+最终使用
  ↓
交付入住（O&M 移交、SB 800 保修）
```

### A.2 六大门禁（Gate 1-6）—— 全流程操作坐标

| 门禁 | 阶段 | 交付物 | 放行条件 |
|---|---|---|---|
| **Gate 1** | 产品/合规路径锁定 | 合规路径图、ESR适用矩阵（UHPC）/规范替换表（钢/木） | 路径确认 |
| **Gate 2** | 设计冻结 | 委派设计计算书、DAA 批准图纸、加州SE复核签章 | 图纸 DAA 批准 |
| **Gate 3** | 开工生产 | 配合比/材料批准、首件样板、工厂QA计划批准 | FQP 批准 |
| **Gate 4** | 模块出厂放行 | FAT/ITP 完成、HCD insignia、NCR 关闭、QAA 签字 | 三重放行齐 |
| **Gate 5** | 现场结构闭合 | 基础验收、就位/连接/密封/封堵/接线完成并检验 | 现场检验通过 |
| **Gate 6** | 入住交付 | 现场 AHJ 最终检查、CO、调试、竣工图+O&M 移交 | 交付入住 |

## D. 使用顺序（如何把框架落成项目 SPEC）

1. **选类型** → 打开对应 02/03/04（每份自带 0.4 合规分布 + 中美对应指针）。
2. **挂共享** → 复用到 `01_共享框架`（Division 00/01/07/13通用/21-28/31-33/48）作为通用骨架。
3. **对材料** → 用 `06_材料设备清单（含中美对应 GB↔US）`逐项写「产品/材料/供应商」子节，性能句挂美标、加中标对照。
4. **套模板** → 每个 SECTION 按 spec-agent 三段式（Part1 General / Part2 Products / Part3 Execution）五类别（标准/性能/供应商/安装/维保）展开。
5. **对合规** → 每章「安装执行」子节挂 `01_共享框架合规底座·§0.4` 规范分布矩阵的停点（insignia/三重放行/Gate/FAT-SAT/Caltrans/CFC/CEC/ADA）。
6. **用现成章节** → `07_钢结构(05 12 00)/08_UHPC(13 34 23)/09_木覆面板(06 16 00)` 三段式+中美换算表+3停点做模板；其余章节照此展开。
7. **对标竞品** → 参考 `05_供应商SPEC做法对标` 决定文档形态（Spec Sheet / Plan Set / 安装手册 / ESR 四件套 or 项目级 BIM+QTO+公章）。
8. **给美方概览** → 用 `00_Executive_Summary_EN`（英文总览）沟通国际/融资伙伴。
9. **跟踪动态（平台 L2）** → 用 `10_标准与竞品动态跟踪清单L2雷达` 的条目标频率/触发器，后续叠 cron 生成「标准异动简报/竞品月报」，有选择发布到平台「动态」专区。
10. **平台长期** → L1 知识库接入 spec-agent 母本（modular=特例视图）+ 现有交付；L4 运营中台从 knowledge-channel 建筑图谱抽取「Modular House」标签内容回流。目标：静态站起步，中文主体 + i18n 英文版预留。
