# 可投用 SECTION 三件套

> 三份**可直接投用**的 MasterFormat 三段式完整条款，是「完整版 SPEC 框架」中已深化到可发合同的样板。其余 SECTION 照此模板展开。

## 三份样板

| SECTION | 结构类型 | 内容亮点 | 页面 |
|---|---|---|---|
| **05 12 00** 结构钢框架 | 钢结构 | 三段式 + 材料替换换算表(CN↔US) + 3 停点(HP-1/2/3) | [07](./07-section-steel) |
| **13 34 23** 预制结构(UHPC) | 混凝土/UHPC | ESR-5874 适用矩阵 + 中美对应 + 3 停点 | [08](./08-section-uhpc) |
| **06 16 00** 木覆面板 | 木结构 | 剪力连续性 + 火/烟封堵 + 3 停点 | [09](./09-section-wood-sheathing) |

## 三部曲模板（通用写法）

每份 SECTION 均含：
1. **Part 1 General**：范围、引用文件（美标验收基准）、提交、QA、交货存储
2. **Part 2 Products**：⭐材料替换换算表（US 基准 ↔ CN 对标）+ 材料/焊材/防腐
3. **Part 3 Execution**：工厂/现场/连接/检验 → 3 个 Hold Point 表 → 验收汇总表（可进合同）

## 3 个 Hold Point（通用规则）
- **HP-1 出厂前**：材料证书/FAT/扭矩或强度 + insignia → 放行
- **HP-2 现场就位前**：基础交接、锚栓复核(±2mm)
- **HP-3 连接后/隐蔽前**：焊缝/强度/水密/防火/抗震 + NCR 关闭 + 三重放行

## 用法
把对应段落复制进项目 SPEC，填 `[待定]` 处即可发出；Part 2/3 验收项可进采购/合同。同一模板适用于其余 SECTION（见 `spec/divisions/*`）。
