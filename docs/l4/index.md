# 运营中台 L4 —— 知识回流与积累

> 平台的知识**积累沉淀**层：把其他地方积累的知识汇聚到本平台，并有选择地发布共享。

## 知识回流通道

- **knowledge-channel 建筑图谱**：凡是打了 **「Modular House」标签**的节点/内容，可**有选择地发布共享**到本平台（L1 知识库）。
- 机制：为建筑图谱 → Modular House 标签内容设置「精选/可发布」标记 → 定期同步到 L1。
- 节奏：周度扫描新增标签内容，筛选可公开项。

## 与 spec-agent 大库的关系

- **Modular House 是 spec-agent 大库的特例**。
- L1 实际接入 spec-agent 母本（通用 MasterFormat/SPEC），modular 作为**特化视图**，避免重复维护。
- 本中台负责把「母本 → 特例 → 平台发布」的流转管起来。

## 中台产出物（示例）

- 标准异动简报（由 L2 cron 生成）
- 竞品月报（分品类对标刷新）
- 个案技术论证服务单（L3）
- 知识库更新日志
