# Modular House 美国市场 · 标准与竞品动态跟踪清单（L2 雷达）
> 📌 **平台 L2「动态雷达」的落地点**：分品类竞品对标 + 标准/法规异动。
> - **用途**：作为「标准与竞品动态跟踪」的完整条目清单，后续叠 cron 自动生成「标准异动简报 / 竞品月报」，并有选择地发布到平台（中文主题，i18n 预留英文版）。
> - **跟踪节奏**：每个条目标 `频率`（周/月/季/年/事件驱动）与 `触发器`（触发一次核对/更新的条件）。
> - **对标原则**：竞品按**类别**维护「当前最先进对标目标」，随新品/认证动态刷新；不只列名单，明示「为什么它是该类标杆」。

---

## A. 结构性决策锚（先读这段，规范所有条目）

- **更新频率总约定**：标准条款（ASTM/AISC/NDS/ACI 等）→ 季度核对版本号；法规（加州/联邦）→ 月度；竞品（分品类）→ 周度扫描 + 事件驱动（ESR/融资/倒闭/新品）；进口/关税 → 事件驱动。
- **每个条目推荐落库方式**：`read_me`（一条跟踪项 + metadata.category + framing 标签）→ 供平台「动态」专区调用。
- **英文版预留**：清单字段含 `EN` 列，未来一键 i18n。
- **来源层级**：主来源 = 官方标准组织（ICC/DOI/ASTM/AISC/NDS/ACI/HCD/IHCDA）+ 权威网站（boxabl.com/technical-docs、ARCAT/Sweets/4specs）+ 检索核验；次级 = 新闻/研报，需交叉验证后发布。

## E. 运营中台积累（L4：从 knowledge-channel 建筑图谱抽取）⭐

> 按用户指示：在 **knowledge-channel 的建筑图谱**中，凡是打了 **「Modular House」标签**的节点/内容，**有选择地发布共享**到本平台（L1 知识库）。这是一条「知识回流」通道。

- **机制**：为建筑图谱 → Modular House 标签内容设置「精选/可发布」标记 → 定期同步到平台 L1。
- **节奏**：周度扫描新增标签内容，人工（或规则）筛选可公开项。
- **与 spec-agent 大库关系**：Modular 是 spec 大库的**特例**——L1 实际接入 spec-agent 母本，modular 作为特化视图，避免重复维护。
