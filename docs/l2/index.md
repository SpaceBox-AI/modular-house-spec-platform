# 动态雷达 L2 —— 标准异动 / 分品类竞品对标

> 平台核心增值区：**动态刷新**美国市场标准与竞品动态，替中国供应商掌握「美国市场对产品的基本要求」与「最先进对标目标」。

## 板块

| 板块 | 说明 |
|---|---|

## 更新节奏（约定）

- 标准条款：季度核对版本号
- 法规（加州/联邦）：月度
- 竞品（分品类）：周度扫描 + 事件驱动（ESR/融资/倒闭/新品）
- 进口/关税：事件驱动

## 竞品对标原则

竞品按类别维护「当前最先进对标目标」，不只列名单，明示「为什么它是该类标杆」；新品 / 认证 / 财务异动即触发刷新。

> 对标类型：B1 整机集成（Boxabl/Plant Prefab/Stack/CIMC-MBS/…）· B2 结构分项（AISC 钢构厂/UHPC ESR 持有者/CLT 厂）· B3 围护机电卫浴 · B4 检测认证（ICC-ES/HCD/QAA）。
