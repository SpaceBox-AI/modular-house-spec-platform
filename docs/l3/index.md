# 技术论证服务 L3

> 平台替供应商做的**技术论证**：不只给文档，而是帮中国供应商逐项论证「产品是否符合美国市场基本要求」。

## 四大服务

| 服务 | 内容 |
|---|---|
| 产品美标初评 | 某产品/模块是否符合美标（ASTM/AISC/NDS/ACI/NFPA/UL/CBC）；给出差距项 |
| 深化 SPEC | 把初评纳入，按 MasterFormat 展开成可投用 SECTION（三段式 + 中美对应） |
| 审批流程路径 | 类似 UHPC docx 所述的产品**审批流程**（DAA→QAA→insignia→地方 AHJ→交付） |
| 全生命周期 stakeholder | 整个建筑生命周期中不同**利益相关方的角色、责任与义务** |

## 全生命周期 stakeholder（示例框架）

| 阶段 | 利益相关方 | 角色 / 责任 / 义务 |
|---|---|---|
| 设计 | 供应商 / 委派设计 SE / DAA 审图 | 结构/底盘/吊装/集成设计，加州 SE 复核 |
| 生产 | 工厂 / QAA / HCD | 配合比、FAT、Title 25 §3032 检率 |
| 出厂 | HCD | insignia 贴附（HSC §19980）+ 三重放行 |
| 运输 | 承运商 / Caltrans | 限重限高、运输保护 |
| 现场 | 吊装队 / 现场 SE / 地方 AHJ | 就位、连接、隐蔽前验收、CO |
| 运营 | 业主 / 物业 / SC 保修 | 保修、维护、SB 800 |

> 具体到某产品类型，可据此 + L1 知识库逐阶段展开「stakeholder 责任矩阵」作为可交付服务单。
