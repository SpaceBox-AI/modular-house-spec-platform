## 供应商机电管线系统要点
- **SI 分离**：管线入顶/墙/地空腔，可原位更换。
- **给排水**：微负压排水（防臭防漏）、同层排水、气液分离、大半径弯头，工厂预制 + 现场快接。
- **电气**：低压灯带快接（水口连接器）、大功率快装接线（分线盒 + 三通/直连，免穿管）。
- **合规**：涉水 NSF/ANSI 61；电气 UL/NRTL；管道 IAPMO/CPLC（Title 24 P5）；消防 NFPA 13/13R + 72。
