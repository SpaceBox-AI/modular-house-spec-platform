# 钢结构视图 · 解决方案 B：逐层钢框架 + 内装/部品（汉尔姆示范）

> 供应链解决方案 B —— **Low-rise Assembled Steel + 装配式内装/机电管线部品**：工厂做主次梁框架（梁柱铰接、可选耗能器）+ 装配式精装/机电管线部品，现场组装框架后再拼装内装与管线。**本项目案例供应商：汉尔姆建筑科技有限公司（halumm, halumm.com）**。
> 回到 [钢结构类型总览](steel)。

## 解决方案 B 是什么
汉尔姆是「装配式绿色建筑整体方案商」，主打酒店/公寓装配式精装五大系统 + **Low-rise assembled steel 耗能支撑钢结构体系**（≤3-9 层，梁柱铰接 + 可选耗能器）。它不是整箱 volumetric 整合商，而是**框架做轻、内装/管线做部品可拆改**的出海形态——合规走 FBH 工厂体制 + 部品认证路径。

### 与解决方案 A（整箱）的关键区别
| 维度 | B. 逐层框架+内装 | A. 整箱 Volumetric |
|---|---|---|
| 结构单元 | 梁柱铰接框架 + 耗能器 | 整箱模块本体（13 42）|
| 工厂输出 | 框架构件 + 内装/管线部品 | 整箱（含内装机电）|
| 现场进度 | 组装框架 + 拼装部品 | 吊装为主 |
| 合规锚点 | AISC Qc/Qa + 部品 UL/NSF/ESR | Title 25 §3032 模块厂检 |
| 内装资产 | SI 分离、可拆改（重点） | 出厂即装 |
