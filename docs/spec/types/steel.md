# 钢结构视图（Steel）

> 钢结构是 Modular House 最主流的结构体系之一。**同一钢结构体系下，因供应链出海形态不同，SPEC 展开路径分成两条**——这是本页的核心导航。

## 钢结构体系下的两种供应链出海形态

钢结构 Modular 项目，按"工厂供到哪一级"分为两种出海形态。**供应商先定体系（钢结构），再选自己的供应链形态**，即可进入对应的 SPEC 路径。

| 供应链形态 | 工厂供什么 | 现场做什么 | 代表企业 | SPEC 路径 |
|---|---|---|---|---|
| **A. 整箱 Volumetric 整合商** | 整箱模块（含结构+内装+机电）在工厂完成 | 现场只吊装+连接+调试 | CIMC-MBS、Stack | [→ 进入 Volumetric 视图](steel-volumetric) |
| **B. 逐层钢框架 + 内装/部品** | 钢框架（梁柱铰接、可选耗能器）+ 装配式内装/机电管线部品 | 现场组装框架 + 拼装内装/管线 | **供应商**（本项目示范） | [→ 进入 逐层框架+内装 视图](steel-frame-interior) |

> **形态对比一句话**：解决方案 A 赌"整体交付与吊装效率"，解决方案 B 赌"框架做轻、内装/管线可拆改、货运灵活"。两者都走钢结构美标主线，但合规重心（AISC Qc/Qa、工厂检验、FAT/SAT 停点）落点不同。

## 两种形态的合规差异速览

| 维度 | A. 整箱 Volumetric | B. 逐层框架 + 内装部品 |
|---|---|---|
| 结构体系 | 模块本体=结构单元（13 42 钢模块） | 梁柱铰接框架 + 耗能器（05 12，≤3-9 层） |
| 工厂检验 | 整箱出厂，Qc/Qa 工厂资格 + FAT/SAT 双重停点 | 框架车间加工 + 内装/管线部品厂验 |
| 现场进度 | 吊装为主（01 66） | 现场组装框架 + 拼装内装（安装章节） |
| 货运 | 整箱运输（体积大、牵引车） | 构件/部品分拣运输（灵活） |
| 内装资产 | 出厂即内装完成 | 装配式内装部品（SI 分离、可拆改） |
| 机电 | 箱内深化一体 | 管线系统工厂预制 + 现场快接（SI 分离） |
| 重合规锚点 | Title 25 §3032、CBSC 模块工厂厂检 | AISC Qc/Qa + 部品 UL/NSF/ESR 认证 |
