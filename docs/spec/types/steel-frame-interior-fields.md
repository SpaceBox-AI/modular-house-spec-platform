# 🧾 登录后 · SPEC 关键字段登记总入口

> **供应链解决方案 B · 逐层钢框架+内装**（供应商）→ 字段主数据
> SPEC 由系统依据**登录供应商**上传的资料与基本信息**自动生成**。本页是生成引擎的**字段登记总入口**——展示登录后需填的关键字段分四层（P0–P3），逐层填充、逐步解锁 SPEC 生成能力。
> 回 [解决方案 B 逐层框架+内装 总览](steel-frame-interior)｜[合规核对清单](steel-frame-interior-compliance)

## 生成逻辑一句话
> 系统按 **身份(P0) → 资质合规(P1) → 产品(P2) → 性能核验(P3)** 顺序取数，组合判定后自动生成完整 SPEC（合规清单 + 各 SECTION 三段式 + 性能表），可导出 Markdown / Word / PDF。

---

## P0 · 身份主数据（登录自动带）

账号级字段，登录后系统自动附带；`供应商名称` 即**登录名**（替换页面「供应商」占位符的来源）。

| 字段 | 类型 | 必需 | 生成用途 |
|---|---|:--:|---|
| 供应商ID | uuid | ✔ | 全站归属、URL 参数 |
| **供应商名称（登录名）** | string | ✔ | 替换「供应商」占位，SPEC 标题/页眉 |
| 简称/英文名 | string | 选 | 导出文件名、合同标题 |
| 品牌清单 | string[] | 选 | SPEC 品牌展示 |
| 联系人 | object | ✔ | 提交资料页、责任书签名 |
| 国家/工厂地 | enum | ✔ | 出口检验路径 |
| 工厂地址清单 | string[] | ✔ | FBH 厂检、HCD insignia 关联 |

---

## P1 · 公司资质·合规主数据（入驻时确定，**决定合规路径**）

这是**最关键的合规判定层**——组合判定生成哪套合规骨架。

| 字段 | 类型 | 选项 | 影响条款 |
|---|---|:--:|---|
| **出海形态** | enum | A 整箱 Volumetric / B 逐层钢框架+内装 | 选 SPEC 骨架（A/B 双路径） |
| **FBH 工厂体制** | enum | FBH / site-built / NA | FBH → Title 25 §3032 第三方检验 |
| HCD insignia | bool | — | 贴 insignia（HSC §19980） |
| **委派/合格设计责任** | enum | DAA / QAA / neither | 责任书、DAA 图纸标注 |
| 物理责任范围 | enum | 框架 only / 框架+MEP / 整单元 | SECTION 覆盖 |
| **AISC Qc/Qa** | enum | 单件/体系制造/等效 | 00 41 制造商资格 |
| ISO 9001 | bool | — | 质量凭证 |
| 加州赴厂检验接待 | bool | — | 厂检停点 |
| 财务能力证明 | bool | — | 00 41 供应风险 |
| 委派设计责任书 | bool | — | 01 33 提交 |
| 加州 SE 复核 | bool | — | 结构计算书（AISC 360） |
| 设计规范 | enum | AISC 360 / CBC / ASCE 7 | 规范版本 |
| 复核 SE 执业号 | string | 复核时必填 | 责任书归档 |

---

## P2 · 产品主数据（每产品/项目录入，**解锁各 SECTION**）

决定哪些 SECTION 生成、钢材换算、机电覆盖。

| 字段 | 类型 | 用途 |
|---|---|:--:|
| **结构体系** | enum | 钢/耗能/UHPC/木/volumetric → SECTION 启用 |
| 连接方式 | enum | 铰接/刚性/耗能器 → 05 12 节点条款 |
| 最大层数 | int | 低层 3–9 层条款 |
| 目标抗震区 | enum | 加州 D/E → ASCE 7 高烈度 |
| 机电范围 | enum | 快接/SI/微负压 → 21–28 SECTION |
| 整体卫浴 | bool | 22 41 SECTION 是否启用 |
| 主材对照 | mapping | 中↔美标牌号（A992↔Q355…） |
| 部品清单 BoM | object[] | 21–28 覆盖映射 |
| 模块/框架 ID 规则 | string | FQP 可追溯 |
| 项目名 / 州 / 依据规范 | string·enum | SPEC 标题、州级差异、规范基准 |

---

## P3 · 性能核验值（逐 SECTION 填写，**回填生成**）

P3 即现有 13 张**在线填写表**的「供应商填写值」。系统在生成期做**数值区间核验**（对照美标参考值），未填标「待填」。

| SECTION | 系统 | 填表页 |
|---|---|:--:|
| 05 12 结构钢框架 ⭐ | 钢框架 | [→ 填写](steel-frame-interior-0512) |
| 06 16 内衬面板 | 内装基层 | [→ 填写](steel-frame-interior-0616) |
| 09 51 吊顶 / 09 72 墙面 / 09 68 架空地面 / 09 67 地坪涂料 / 09 51-97 卫浴防水 / 13 48 抗震连接 | 内装 | 各自填写页 |
| 21 消防 / 22 给排水 / 22 41 整体卫浴 / 26 电气 / 23 暖通 | 机电 | 各自填写页 |

---

## 📋 生成输出（填完后系统自动产出）
1. **合规核对清单**（00-41/01-33/01-43/01-45）→ [核对清单页](steel-frame-interior-compliance)
2. **各 SECTION 三段式 SPEC**（PART1 一般 / PART2 产品 / PART3 执行+停点）
3. **性能表**（美标参考 + 供应商填写值 + 标准）→ 导出 Markdown / Word / PDF
